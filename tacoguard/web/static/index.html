                      Website blocking

                      TacoGuard keeps two lists of known bad websites and warns you when this PC looks one up or a program connects to one. It only warns: it never pauses or ends a program for a website. Microsoft Defender's own SmartScreen keeps working as before.

                      Website lists

                        Block in every browser (hosts file)

                        Windows' hosts file can send these websites nowhere, in every browser and program. Changing it needs administrator rights, so Windows asks you each time (a prompt from Windows, not from TacoGuard). The first time, the prompt shows "Windows PowerShell" and TacoGuard installs a small helper into Program Files\TacoGuard, a folder only administrators can change. TacoGuard writes only its own marked section, keeps a copy of the original file once, and never lists Microsoft's or other important websites.

                        Checking...

                        Your abuse.ch key

                        abuse.ch is a non-profit project that tracks malware and the websites that spread it. Its key is free for personal, non-commercial use: sign in at auth.abuse.ch, copy your Auth-Key and paste it here. TacoGuard then looks up files it flagged on MalwareBazaar (it sends only the file's fingerprint, never the file) and downloads the URLhaus list.

                        Checking...

                        The key is kept encrypted for your Windows account only. This page never shows it again, only its last 4 characters.
